# Changelog

## [0.1.0] - 2026-10-26

- Anchor program with client-created receipts, provider delivery claims and client acknowledgments.
- PDA validation, signer authorization and one-way state transitions.
- TypeScript client and CLI for hashing, signing and inspecting receipts.
- Read-only dashboard with timelines, filters, public values and JSON exports.
- Real local-validator demo, automated tests and optional Devnet instructions.

- Installable npm CLI with packaged dashboard assets and a clean-install smoke check.
